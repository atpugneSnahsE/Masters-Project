# Data Processing Module

Data collection, preprocessing, and dataset preparation.

## Files

### Data Collection
- `collect_data.py` - CARLA-based data collection for training
- `frames_extract.py` - Extract individual frames from video files

### Data Verification
- `verify_masks.py` - Verify quality of segmentation masks
- `diagnostics.py` - Diagnostic analysis of data

### Testing
- `calib_test.py` - Camera calibration validation
- `test.py` - General testing utilities
- `test2.py` - Additional test cases
