# Lane Detection Module

Core lane detection and classification algorithms.

## Scripts

- **analyze_lanes.py** - Analyze lane structure and spacing
- **ego_line_classifier.py** - Classify ego lane position using U-Net
- **finetune_vil100.py** - Fine-tune model with full network unfrozen
- **lane_marking_classifier.py** - Classify marking types (solid/dashed)
- **run_lane_markings.py** - Real-time lane marking detection with CARLA
- **run_lane_markings_night.py** - Night-time lane detection pipeline
- **run_lane_model.py** - Inference on CARLA stream
- **train_lane_detection.py** - Train lane detection model
- **train_lane_model.py** - Train on TuSimple dataset
- **train_lanenet.py** - LaneNet architecture training
- **train_vil100.py** - VIL-100 dataset training
- **verify_masks.py** - Verify ground truth masks
